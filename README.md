# Simula-o-Guindaste-com-dois-carrinhos-em-um-trilho
Esse repositório foi criado para armazenar o trabalho de faculdade da matéria de Modelagem de Sistemas dinâmicos.  Nesse trabalho será feita a modelagem do modelo físico 2D de um guindaste de dois carrinhos em um mesmo trilho segurando uma carga plana com cabos flexíveis e perturbações do vento.
